# Audit Artifacts

This directory stores runtime audit outputs generated by `./scripts/audit.sh`.

## What gets generated
- `docs/audit/<timestamp>/RESULT.md`
- `docs/audit/<timestamp>/TRACEABILITY.md`
- `docs/audit/<timestamp>/logs/*`
- `docs/audit/<timestamp>/proofs/*`

## CI artifact location
GitHub Actions uploads `docs/audit/` as artifact:
- Artifact name: `sentinel-audit-artifacts`
- Workflow: `.github/workflows/audit.yml`

## Local reproduction
1. Ensure Docker/Compose is available.
2. Run: `./scripts/audit.sh`
3. Read latest output in `docs/audit/_latest/` and timestamped directory.

Generated timestamped outputs are intentionally ignored by git.
