## 3. REQUIRED FRONTEND STACK

Use this exact frontend stack unless the repo already has an equivalent and keeping it is safer:

* **Next.js App Router**
* **TypeScript**
* **Tailwind CSS**
* **shadcn/ui** for consistent primitives
* **next-intl** for localization and locale routing

* **Recharts** for charts
* **Framer Motion** for tasteful micro-motion only
* **lucide-react** for icons
* **zod** for client-side contract validation

Use `next-intl` because the app must support App Router-compatible localized UX and route-aware locales. ([next-intl.dev][1])

Use `EventSource` because live queue/trust updates are one-way server-to-client streams and SSE is a good fit for that. ([MDN Web Docs][3])

* Format numbers, dates, percentages, currencies, and relative times per locale.

HTML `dir` supports `ltr` and `rtl`, and Arabic is a right-to-left language that should switch directionality accordingly. ([MDN Web Docs][4])

## 9. REAL-TIME UPDATE ARCHITECTURE

Use **SSE / EventSource** for live updates.

Implement:

* queue patch stream
* command center patch stream
* trust patch stream

### Streaming behavior

* initial page uses normal fetch
* stream applies patch-by-ID or patch-by-section updates
* no full-page reload flicker
* rows update calmly
* keep sort order stable
* reconnect automatically on disconnect
* show stream status in a subtle UI badge

`EventSource` opens a persistent `text/event-stream` connection and is designed for server-to-client updates. ([MDN Web Docs][3])

### Required live behaviors

#### Queue

* insert new incidents
* update priority score
* update trust badge
* update owner/status
* remove/close resolved items if filtered out

#### Command Center

* update top incidents
* update “what changed”
* update incident pressure
* update trust strip

#### Trust

* update feed health
* update late-data rate
* update degraded feeds
* update model status

### No high-jank polling

If polling exists today, replace it with:

* initial fetch
* SSE incremental patches
* optional slow fallback refresh only if stream is unavailable
