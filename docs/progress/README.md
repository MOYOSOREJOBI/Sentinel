# Progress Scoring

Progress is computed from weighted rubric S1-S10 (total 100 points).

## Interpretation
- **Completion %**: weighted score achieved.
- **Status**: PASS only when mandatory gates pass.
- **Runtime coverage**:
  - FULL: runtime checks executed with Docker.
  - NONE: runtime checks not executable in current environment.

## Gates
- S1-S10 and G0-G8 are recorded in audit/result artifacts generated by `scripts/audit.sh`.

Generated timestamped progress snapshots are intentionally ignored by git.
